Course Recommender · System Architecture

Hệ thống khuyến nghị khóa học: Retrieval + GenAI/RAG, triển khai trên AWS

Một kiến trúc ba lớp — engine truy hồi, lớp GenAI/RAG, và lớp phục vụ API — ngăn cách bởi một tầng lưu trữ trừu tượng, để cùng một mã nguồn chạy được cả trên máy cá nhân lẫn trên AWS.

2-stage retrieval (FAISS + rerank) RAG · Claude API ⇄ Bedrock FastAPI serving Terraform · ECS Fargate 30 tests · CI/CD
01 — Tổng quan

Kiến trúc tổng thể

Client gọi vào FastAPI. Mỗi request đi qua lớp GenAI (hiểu truy vấn) → engine truy hồi (encode → ANN → lọc → rerank) → và tùy chọn quay lại GenAI để sinh giải thích. Tất cả artifact (vector, index, dữ liệu) nạp qua tầng lưu trữ local hoặc S3.

02 — Luồng dữ liệu

Một request POST /recommend đi qua đâu

Hai tầng truy hồi: tầng recall nhanh (ANN) lấy ứng viên, tầng rerank tinh chỉnh độ chính xác. GenAI bao ở hai đầu: hiểu truy vấn trước, và giải thích kết quả sau — đều có phương án dự phòng tất định nếu không cấu hình LLM.

03 — Chức năng

Các thành phần & nhiệm vụ

Mỗi module có một trách nhiệm rõ ràng và ranh giới sạch, để dễ test, thay thế và mở rộng.

Engine

Pipeline dựng dữ liệu

Đọc CSV → chuẩn hóa cột → làm sạch & ghép text → sinh embeddings → dựng FAISS index → phân cụm KMeans + UMAP → lưu artifacts. Một lệnh: python -m src.pipeline --mode build.

src/pipeline.py · src/models
Engine

Truy hồi hai tầng

Encode truy vấn (TF-IDF hoặc SBERT) → tìm láng giềng gần nhất theo cosine → lọc theo level/category → rerank bằng cross-encoder để tăng độ chính xác.

src/recsys/recommender.py
Engine

Vector index (ANN)

FAISS inner-product trên vector đã chuẩn hóa (= cosine). Tự động fallback sang tìm kiếm numpy vector-hóa khi không có FAISS, nên hành vi giống hệt, chỉ chậm hơn.

src/recsys/index.py
GenAI

Hiểu truy vấn

Biến câu hỏi ngôn ngữ tự nhiên lộn xộn thành một truy vấn ngữ nghĩa gọn + bộ lọc có cấu trúc (level, category). Có LLM thì dùng LLM, không thì dùng heuristic.

src/llm/service.py
GenAI

Giải thích RAG

Retrieval-Augmented: các khóa học đã truy hồi chính là ngữ cảnh nền, nên mô hình giải thích trên kết quả thật thay vì bịa ra danh mục không tồn tại.

src/llm/service.py
GenAI

Trừu tượng LLM

Một interface, hai backend hoán đổi qua biến môi trường: anthropic (Claude API) và bedrock (Claude trên AWS). Trên ECS, Bedrock không cần API key — dùng IAM role.

src/llm/provider.py
Serving

FastAPI service

Các endpoint /recommend, /similar, /courses, /health, kèm OpenAPI docs, đo thời gian request, và nạp model một lần rồi tái dùng.

src/api
Hạ tầng

Trừu tượng lưu trữ

Cùng interface đọc/ghi artifact cho hai backend: hệ thống file local và AWS S3. Đổi từ laptop sang cloud chỉ là đổi ARTIFACT_STORE=s3, không sửa code.

src/storage
Hạ tầng

Hạ tầng AWS (IaC)

Terraform dựng ECR, ECS Fargate sau ALB, S3 cho artifact, IAM role (đọc S3 + gọi Bedrock), CloudWatch logs — theo một lệnh terraform apply.

infra/aws
DevOps

CI/CD

GitHub Actions: CI chạy lint + 30 test + build image; deploy-aws build/push ECR rồi cập nhật ECS qua OIDC; terraform validate hạ tầng.

.github/workflows
UI

Streamlit UI

Giao diện demo mỏng, gọi thẳng API (nên demo chạy đúng luồng như production): tìm kiếm, tìm khóa tương tự, và bản đồ cụm UMAP.

app/streamlit_app.py
Engine

Đánh giá offline

Đo Precision/Recall/NDCG theo nhãn category & skills, và chất lượng phân cụm (silhouette, intra/inter-similarity) để chứng minh chất lượng gợi ý.

src/eval.py

Artifacts sinh ra khi build

Pipeline ghi một bộ artifact nhất quán qua tầng lưu trữ; engine phục vụ đọc lại đúng bộ đó — dù ở local hay S3.
